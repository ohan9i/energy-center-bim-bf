# BIM 조립체 개선 — revision 2 / modelling_version 3

2026-10-10. 기존 파이프라인을 개선하고 로컬 모델·IFC·정적 웹 모델을 재생성했다. 원본 DWG, CAD 리더, BF 탐색/시뮬레이션 알고리즘은 수정하지 않았다. 원격 배포는 실행하지 않았다.

## 현재 결과와 정확도

지하 1층, 지상 1~4층, 지붕 후보의 2,278개 BIM 객체를 유지한다. 423개 조립체에 구성요소 2,255개가 있다. 각 객체의 도면 ID·평면·분류·층·미확정 상태를 보존한다. 조립체 구성요소별 형상과 근거를 JSON과 IFC에 저장한다.

**이 결과는 도면에 근거한 평면과 층 레벨에 임시 상세 치수를 추가한 검토 모델이다. 모든 부재가 확정된 Revit 수준의 정밀 BIM이라는 완료 판정은 하지 않는다.** 기존 보고서의 객체 개수/원본 좌표 근거는 유효하지만, 두께 없는 바닥과 창호 표시 방식에 관한 설명은 이번 변경으로 대체된다.

## 임시 치수와 수정 방법

`bf_bim/assembly_parameters.json`의 수치는 **도면으로 부재 적용이 확인된 값이 아니다**.

| 변수 | 현재 임시값 |
| --- | ---: |
| 구조 슬래브 | 200 mm |
| 바닥 마감 | 30 mm |
| 계단참 / 단 하부 지지 | 각각 150 mm |
| 문 높이 / 문짝 두께 | 2,100 / 40 mm |
| 창 높이 / 창대 높이 | 2,400 / 900 mm |
| 틀 폭 | 50 mm |
| 유리 표시 두께 | 10 mm — 실제 상세의 24/28 mm 사양으로 확정하지 않음 |
| 샤프트 추가 벽 두께 | 120 mm |

기본값을 수정한 뒤 아래 명령으로 재생성한다. 개별 부재는 기존 객체 JSON 편집의 `components`, `source.provisional_opening` 등으로 수정할 수 있다. 문/창 높이를 실제 확인했다면 `height`와 `z_offset`, 구성요소 치수를 함께 맞춰야 한다. `verified`를 확인 없이 켜지 않는다.

```powershell
.\.venv-cad\Scripts\python.exe -m bf_bim.prepare_project
.\.venv-cad\Scripts\python.exe -m bf_bim.publish_model
npm.cmd run build --prefix web
```

`publish_model`은 정적 JSON 갱신이다. 사이트 배포를 실행하지 않는다. 웹의 ‘임시 조립체 입체 표시’를 끄면 임시 두께 구성요소는 면으로 표시된다. 저장 모델과 IFC는 기본 조립체 입체를 보존한다. 원래 측정 바닥과 임시값을 구별하는 화면 옵션이며 임시값이 확정되는 기능은 아니다.

## 반드시 필요한 추가 자료 / 미완성

1. **구조 보: 미생성.** `s-xref-plan`, `s-xref-section` 원본과 구조 부재 위치/부호가 포함된 도면이 필요하다. 현재 부호 문자만으로 보의 좌표·폭·춤을 정할 수 없다. 기둥 사이에 임의 보를 생성하지 않았다.
2. 슬래브 두께·실제 구조 개구부·캔틸레버/지하주차장 외곽: 전체 구조 슬래브 평면과 단면 필요. 현재 도면 폐합 후보와 임시 두께다.
3. 외벽/내벽: 짝 없는 벽면은 여전히 10 mm 위치 표시이며 실제 벽체가 아니다. 부재 높이와 누락 구획은 외부참조 본체/확대 평면 필요. 정확히 모두 일치한다고 주장하지 않는다.
4. 창호 부호 매칭·개정 일치·창대/인방/높이: 평면과 일람표 매칭표 필요. 24/28 mm 유리 적용 부위도 미확정이다.
5. 비기준층 계단 48개 구성요소의 높이는 null이다. 지하/옥탑 단수·참·진행방향 상세가 필요하다. 기준층 높이를 복사하지 않았다.
6. 지붕 경사·파라펫·옥탑 상부와 전체 입면: 프록시를 표준 객체로 변환한 입단면 또는 누락 XREF 필요. 현재 4층 외곽 투영 지붕 후보다.
7. 실 구획 일부 공유 경계와 승강기 카/입구 상세는 여전히 미완성이다.

## 검증과 검토 이미지

Python 18개, 기존 CAD 리더 6개와 웹 26개 테스트, TypeScript/Vite 빌드가 통과했다. 조립체 구멍 보존·기둥 주변 틈 보정 시 보호 개구부 유지·완성 바닥 레벨·12단 계단 접속·벽 중복 제거·IFC 개구부/채움 관계를 검사했다. 바닥 재구성에서 생긴 기둥 주변 폐합 틈 34곳을 보정했으며, 중정/코어 보호 영역은 유지했다.

`verify_model`로 원본 16개 DWG 해시와 CAD ID, 평면/중정/코어를 재검사했다. 기둥 평면 최대 편차는 약 0.643 mm이다. 이 값은 모델 전체 정확도나 임시 두께의 오차를 뜻하지 않는다.

최종 IFC를 다시 읽어 EXPRESS 오류 0건, BIM 객체 2,278개와 조립체 구성요소 2,255개의 좌표·면적·체적 검사를 통과했다. 최대 월드 좌표 차이는 약 3.55×10⁻¹⁵ m이다. 접합 과정의 대각선 마감 벽에 생긴 1 mm 미만 잔여 면을 정리하고, IFC 개구부를 한 번만 절삭하도록 수정한 뒤 전체 검사를 다시 통과시켰다. IFC 재료/개구부 관계를 포함한 교환 정합성 검사이며 도면 정보 부족을 해소했다는 의미는 아니다.

`cad_output/bim-review-exterior.png`, `bim-review-separated.png`, `bim-review-interior.png`, `bim-review-section.png`를 실제 형상 함수로 렌더해 검토한다. 평면 대조는 `bim-cad-comparison.png`, IFC 전체 검사 결과는 `ifc-validation.json`이다. 화면용 그림자는 웹에만 적용되며 이 정적 검토 이미지는 기하학 자체를 보여 준다.

브라우저 도구의 활성 브라우저 목록이 비어 있고 Chrome 생성 요청도 거부됐다. **실제 WebGL 화면 클릭·카메라 조작·프레임 속도 확인은 남아 있다.** 정적 렌더 육안 검토와 코드/형상 검사를 브라우저 검증으로 대신 표기하지 않는다.
