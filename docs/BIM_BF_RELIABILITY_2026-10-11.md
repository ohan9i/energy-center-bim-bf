## 형상과 도면 대조의 실제 범위

원본/생성기 입력 311개를 재생성 전후 SHA256으로 대조했으며 변경 0개다. 평면·단면 DWG는 공간 원장 재생성 시 감사 목록의 원본 해시와도 대조했다. 원본 도면 재추출은 수행하지 않았다.

직전 공개 모델 `1537ae2600caa8f5d7b06c3ab1be9abbf8db21b7`과 요소 ID, 평면 윤곽·구멍, 높이·Z, 구성요소 ID·역할·솔리드 메시를 비교했다. **형상 변경 0개, 요소 삭제 0개, 기존 검증 상태 변경 0개**다. 이번 P0의 직접 수정은 실제 교차하지 않는 호스트 연결 데이터이며, 근거가 없는 형상을 새로 확정하지 않았다. 새 연결 관측 380건도 검증 승격이 아니다.

7개 층의 추출 CAD–모델 평면 대조를 재실행했다. 기둥 윤곽 211개의 최대 경계 차이는 `6.9043e-7 m`다. 이는 추출 자료와 생성 모델 사이의 수치 차이이며 현장 오차나 건물 전체의 설계 정확도가 아니다.

주요 기하 검사에서 개구부 잔여 면적 최대 `1.961e-7 m²`, 슬래브의 보호된 코어·중정 침범 최대 `3.615e-6 m²`, 벽·기둥 중복 최대 `5.879e-7 m²`였다. 정해진 검사 허용 범위를 통과했으며 수학적 0이라고 설명하지 않는다. Draft IFC 2,198개 요소·4,469개 구성요소의 체적·세계 좌표와 IFC4 EXPRESS 검사(문제 0건)를 통과했다. JSON–IFC 좌표 차이 최대 `3.553e-15 m`는 내보내기 내부 일치도다.

계단참 후보 9개는 상층 레벨과 같고 상층 바닥과의 평면 간격이 최대 약 1.43mm다. 2mm 기하 대조 범위의 근접 관측이며 실제 계단 진행 방향·출입구·지지 상세·BF 통행을 검증한 결과가 아니다. 옥상 계단 후보 1개는 입체/상층 연결이 미확정인 상태를 유지한다.

## 미확정 상태와 한계

- 문·창호 중 벽 호스트에 대응하는 것은 86개(문 41, 창호 45), 미대응은 284개(문 57, 창호 227)다. 미대응은 현재 후보 모델의 연결 근거 부족을 뜻하며 실제 건물의 누락된 문·벽 개수로 해석하지 않는다. 임의의 벽이나 개구부로 채우지 않았다.
- 실제 공간 31개, 문 연결 98개, 승강기 층간 후보 10개는 모두 미확정이다. 실제 건물의 BF 요청은 계속 `no_path`다. 테스트 입력의 승강기 성공 경로는 실제 건물 검증 결과와 구분한다.
- 원본 변환 전 DWG의 독립 출력 대조, 누락 XREF, 보 위치/부호·부재 규격·창호 상세 배정, FFL/SSL, 벽·기둥 상하단, 지붕/PIT/파라펫 상세는 미완료다.
- 문 유효폭·문턱 단차·실별 확정 경계·승강기 카/승강장 문/운행 조건·계단 방향의 부재별 확인 기록이 필요하다. 검토 기록이나 기하 경로를 공식 BF 인증 판정으로 사용하지 않는다.
- BIM 의존성 토큰 변경으로 과거 공간 수정본이 재검토 대상으로 남을 수 있다. 수정 파일/브라우저 저장값을 삭제하지 않고 `stale_preserved`로 보존한다.

## 산출물과 코드

현재 공개 모델: `web/public/models/precision-rebuild.json` 및 같은 폴더의 IFC 두 개.

로컬 생성기 수정: `bf_bim/precise/coordination.py`, `coordination_quality.py`, `bf_bim/spatial_navigation.py`. 이 파일들은 작업 시작 때부터 미커밋된 정밀 모델링 작업에 속한다. 다른 미커밋 작업과 함께 로컬에서 보존하며, 웹 배포 커밋에는 공개 런타임·현재 모델·웹 테스트·이 보고서만 포함한다.

검사 근거: `cad_output/precision-rebuild/coordination-v2/`의 `reliability-improvement.json`, `junction-validation.json`, `validation.json`, `plan-validation.json`, `preservation.json`, `browser-current/`와 `cad_output/bf-spatial/preservation.json`. 상세 원본과 생성기 입력은 공개 자산에 포함하지 않는다.
