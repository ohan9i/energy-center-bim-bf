## 1. 실제 수정한 형상과 위치

- 3층 `coord-00088d6131cb5fe92e68`, 4층 `coord-0aa6a2cc9653d0908c64`: `win-f-fff` 블록의 꺾인 창호를 하나의 최소 외접 사각형 축으로 생성하던 오류를 수정했다. 범위는 X 35.890~42.077 m, Y 24.257~32.035 m다. 원본 `A04-001~008` 추출의 각 부재 CAD ID만 사용해 평행 면 쌍을 다시 구성하고 **두 방향의 창호 구간**으로 입체화했다. 내부 유리 면 쌍을 별도 창호로 중복 생성하지 않으며, 각 구간의 횡방향 CAD 선에서 중간 프레임 위치·관측 폭을 다시 얻었다.
- 두 창호는 각각 윤곽 밖 약 **1.690019㎡**가 생겼고, 실제 후보 윤곽 안에 표현된 투영은 약 **0.029981㎡**에 불과했다. 수정 후 후보 윤곽 안의 투영은 각각 **1.626006㎡**다. 후보 윤곽 자체는 1.6281835㎡다. 남은 차이를 임의 채우지 않았다. CAD 선과 캐시 윤곽의 반올림·모서리 및 프레임 상세는 별도로 미확정이다.
- 일반 창호는 반올림된 평면 윤곽과 원래 실수 축 좌표를 섞어 생성하면서 윤곽 밖에 생기던 띠를 원래 윤곽과 교차시켜 제한했다. **1층 40개**, 전체 **200개**의 실제 형상이 변경됐다. 수직 치수는 기존 미확정 가정을 유지했다.

## 2. 도면·좌표 정합성 및 접합 검사

CAD mm → BIM m 배율 0.001, 축 회전 0, 1층 원점 `(32920000, -5730000)` mm, 도면 간 X 이동 `126150.00007091` mm를 사용한다. Z는 `EL - 37.70` m다. B1/1F/2F/3F/4F/roof/phroof 레벨은 `-3.9 / 0 / 4.2 / 8.4 / 12.6 / 16.8 / 22.2` m다. 옥상·옥탑·PIT의 개별 높이 배정은 미확정이며 원점을 현장 측량 좌표로 설명하지 않는다.

기존 추출 기둥 제어점의 층별 상대 정렬은 B1 42개, 1F 42개, 2F 40개, 3F 39개, 4F 38개가 대응하며 최대 중심 잔차는 약 `4.20e-9 m`다. 이는 상대 도면 배치 검사이며 구조 부호·개정 일치의 승인이 아니다. 재실행한 기둥 윤곽 211개의 CAD 추출–모델 최대 경계 차이는 `6.9043e-7 m`다. 원점·단위·축 방향에 새로 확인된 오류가 없어 해당 변환과 층 높이를 바꾸지 않았다.

## 3. BF 공간·경로 개선과 검증

Python 공간 원장 및 웹 `physicalBlockers`에서 창호가 장애물 목록에서 누락돼 있었다. **272개 창호**의 현재 평면 윤곽을 통과 불가 영역으로 반영했다. 창호 높이·개폐·하부 통행 조건이 미확정이므로 일반 출입문처럼 통과시키지 않는다. 실제로 통과 가능한 창호가 있다면 해당 부재의 도면·통행 조건을 별도로 검토해야 한다.

- 창호를 원장에서 빠뜨려도 웹이 현재 BIM에서 장애물을 다시 생성한다. 승인된 문이 다른 창호를 절단하지 못한다.
- 1층의 창호 장애물은 53개다. 변경된 형상으로 공간 경계를 다시 차감하고 NavMesh를 재생성했다.
- 의존성 토큰을 Python·TypeScript 모두 `bf-model-dependencies/3`으로 갱신했다. 이전 확인 기록은 현재 형상·장애물 처리와 다시 대조해야 한다. 오래된 사용자 수정본은 삭제하지 않고 보존한다.
- 회귀 테스트에서 복도를 가로막는 창호와 문 접근부에 겹친 창호 모두 `no_path`다. 기존 두 승강장 문을 사용하는 합성 테스트 경로는 유지했다. 합성 테스트는 실제 건물의 통행 성공 사례가 아니다.

실제 공간 31개, 문 연결 98개, 승강기 층간 후보 10개는 여전히 미확정이다. 실제 1층 홀 `[35.53395, 42.17935]`와 회의/세미나 위치 `[50.32016, 55.47793]`는 각 후보 공간에 포함되지만, 경계·바닥 조건과 중간 문 연결이 확인되지 않았다. 1층 승강기 위치 두 곳은 확인된 카 공간을 갖지 않는다. **실제 1층 및 층간 요청은 전후 모두 `no_path`**이며, 검증된 출발·도착 쌍을 임의로 만들지 않았다. 경로 존재와 BF 법적 적합성은 별개이고, 이번에 BF 인증 완료로 승격한 항목은 없다.

## 5. 미해결 문제와 이유

원본 변환 전 DWG의 독립 출력 대조와 누락 XREF 확인은 미완료다. 창호 부호·높이·하부 레벨·재료·꺾임 상세, 보 위치/규격 적용, 벽·기둥 상하단과 FFL/SSL, 지붕 경사·PIT·파라펫은 부재별 근거가 충분하지 않다. 기존 가정을 실제 설계값으로 바꾸거나 없는 부재를 생성하지 않았다. Verified IFC는 입체 부재 0개를 유지한다. 건물 전체가 완성됐다고 보고하지 않는다.

## 6. 다음 최우선 작업

1층 홀–회의/세미나 구간의 **원본 실 경계와 출입문 호스트·유효폭·문턱 단차**를 부재별로 확정하는 것이 우선이다. 해당 공간을 나누는 누락 XREF/경계 선과 문 상세를 확인해야 실제 통행 쌍을 확보할 수 있다. 그다음 승강장 문·카 바닥·운행층을 확인해 층간 경로를 연결한다. 보·창호 수직 치수는 위치와 상세/규격표가 함께 대응하는 부재부터 배정한다.
