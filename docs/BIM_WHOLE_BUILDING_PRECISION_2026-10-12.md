## 실제 반영한 형상

회전호의 반지름과 방위를 출입문 전체 조립체의 폭·축으로 사용하던 공통 로직을 수정했다. 원본 A04의 폐합 문틀 두 개, 내부 연결선, 회전호의 경첩 측과 문짝 평면 윤곽을 함께 대조한다. 중복된 양개문 문짝 객체 10개는 23개 실제 개구부 조립체에 통합했다. 제거된 문짝의 ID와 CAD 회전호는 부모의 `native_door_evidence.original_leaf_candidates`에 보존한다. 실제 통과 가능한 문 10개를 삭제한 것이 아니다.

벽체는 원본 벽선과 기둥선으로 실제 닫히는 얇은 영역을 찾고, 기존 벽·기둥·문·창의 영역을 뺀 **96개 접합부, 약 6.982㎡의 평면 형상**을 복구했다. 모서리와 기둥 접합부에서 기존 평행면의 공통 길이만 취해 끝부분이 잘리는 것이 원인이었다. 열린 선을 연장하거나 일정 두께로 부풀려 벽을 만들지 않는다. 10mm 내부 여유가 없는 수치 잔여는 이번 복구에서 제외하되 기존 자료는 보존한다. 새 벽의 층간 높이는 기존 단면 레벨에 따른 시각화 가정이며, 개별 벽 상단이나 구조 역할의 확인을 뜻하지 않는다.

## BF 데이터와 공간 미완성

실·복도 후보 31개와 승강기 연결 후보 10개는 미확정이다. 실제 건물 1층 홀→회의실 등의 계산 결과는 계속 `no_path`이며 실제 검증 성공 사례를 만들지 않았다. 문 개구부의 형상이 맞는 것, 두 공간이 실제 연결되는 것, BF 법적 기준을 만족하는 것은 각각 별도로 확인해야 한다.

## 확인한 도면 누락과 높이 충돌

사용자가 지정한 `에너지-건축도면` 원본 30개와 해당 원본 해시가 일치하는 추출 자료를 사용했다. 구조/상세 DWG의 외부 참조 목록과 블록 내부도 확인했다. 현재 추출에서 다음 외부 참조 파일이 없고, 참조 블록의 저장 형상 객체 수는 0이다.

- `s-xref-plan.dwg`: 구조 보 위치·슬래브 실제 경계.
- `s-xref-section.dwg`: 구조 부재 상하단 및 단면 연결.
- `xref-plan.dwg`, `xref-section.dwg`, `xref-elev.dwg`: 코어·외벽 상세의 본체 형상.

프로젝트 복사본 ZIP에도 위 파일은 없었다. 상세 도면의 제목·레벨·규격 문자열이 존재해도 그 본체 형상이 함께 존재하는 것은 아니다. `structural-native-f1.png`에는 구조 부호·주석은 있지만 보의 실제 평면 본체가 없음을 기록했다. 변환 추출 결과의 한계이며 독립적인 DWG 무손실 검증 완료로 표현하지 않는다.

건축 단면·상세의 `EL+59.90`과 구조 단면 등의 `EL+59.30`이 함께 있어 **상부 레벨 600mm 차이**가 남아 있다. 지붕/파라펫/슬래브의 서로 다른 기준인지 개정 차이인지 본체 단면 없이 확정할 수 없다. 임의로 한 값을 선택해 지붕이나 계단을 늘리지 않았다. 기존 A04 층 높이 후보는 유지한다.

전체 구조 보·슬래브 경계, 코어 본체, 외장/지붕 접합을 다음 단계에서 확정하려면 누락 외부 참조가 포함된 묶음 또는 XREF가 결합된 도면이 필요하다. 이와 함께 남은 1층 공간 경계를 실제 평면과 개별 대조해야 한다.

## 검증과 재현

최종 모델로 Python 전체 **97개**, CAD 리더 **6개**, 웹 **66개** 테스트를 통과했다. TypeScript/Vite 프로덕션 빌드와 Pages 하위 경로 HTTP 검사도 통과했다. Chrome/WebGL에서 전체·층별·단면·실내·기존 창호·다운로드·경로·사용자 저장 보존 19개 화면을 검사했고, 복구 벽체 2개와 SSD-3 닫힘/열림 2개 화면을 추가 확인했다. 브라우저 실행 오류와 HTTP 오류는 0건이다. 실제 건물은 `no_path`, 별도 합성 테스트 모델만 32.6m 경로를 유지한다.

Draft IFC의 요소 2,284개·구성요소 4,761개 전체에 대해 솔리드 체적·월드 좌표를 대조했다. IFC4 EXPRESS 문제 0건, 최대 좌표 차이 약 `2.85e-7m`다. 새 벽의 최종 수치 정리된 단면을 동일하게 삼각형 입체로 변환해, 복잡한 오목 단면의 IFC 압출 과정에서 일부 체적이 달라지던 오류도 수정했다. 기존 1μm 좌표 격자·10μm 단순화·필요한 0.1mm 수치 잔여 처리는 `numeric_cleanup`과 `omitted_boolean_slivers`에 기록한다. 삼각형 변환이 추가적인 외형 보정을 하지는 않는다.

문/창 호스트 개구부 검사 142건은 모두 통과했다. 슬래브와 보호 개구부의 최대 중복은 약 `3.61e-6㎡`, 벽·기둥의 최대 평면 중복은 약 `8.29e-7㎡`다. 이 수치 검사는 실제 도면의 모든 부재·높이·접합을 승인한 것이 아니다. IFC에는 출입문 유형 1개, 창 유형 6개, 유형에 연결된 객체 17개와 개구부/벽 관계 140개를 보존했다. Verified IFC에는 검증 완료 부재가 없고 층 구조만 있다.
