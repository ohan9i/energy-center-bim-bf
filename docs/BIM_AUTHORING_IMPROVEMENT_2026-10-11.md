- 창 29개의 원본 프레임을 복원·대조했다. 그중 21개에서 외곽 폭 오류를 수정했다.
- 양 끝 프레임 폭은 CAD에서 읽은 치수를 사용한다. 나머지 미연결 창의 높이·창대·인방 프레임 치수는 가정으로 유지한다.

- 적용 창 16개 모두에서 원본 평면의 평행 면 간격 24mm를 대조했다. 프레임 중심에 놓였던 유리를 해당 원본 면 위치로 옮겼다. 대표 창은 프레임 중심에서 유리 중심까지 63mm 치우쳐 있으며, 방향은 개별 창의 원본 축을 따른다.

기존 벽은 부모 높이 없이 실제 높이가 있는 하위 구성요소로 만들어졌다. 이전 IFC 내보내기는 부모 높이가 없다는 이유로 개구부 관계를 건너뛰었다. 이를 수정해 **기록된 벽 높이 범위와 실제 호스트 절단 다각형**을 사용한다. 부모 벽의 입체를 임의로 추가하거나 이미 절단한 자식 입체를 다시 변경하지 않는다.

하나의 창·문이 여러 벽 조각에 걸친 경우 여러 절단 관계가 있을 수 있다. 각 문·창의 채움 관계는 IFC의 단일 연결 제약을 유지한다. 숫자 159·100이 실제 건축물의 전체 개구부 수나 검토 완료 수라는 뜻은 아니다.

기존 속성 패널에서 적용 창호 기호, 폭·높이·창대, 복층유리 구성과 도면 적용 위치를 확인할 수 있다. 도면 대조 상태와 최종 검증 상태를 구분하며, 가정 형상을 숨기는 모드에서 미검토 도면 대조 부재를 검증 완료 입체처럼 표시하지 않도록 수정했다. UI 전체 구조·디자인은 유지했다.

## 정합성·BF 검사

- 원본 CAD 외곽 검사는 1µm의 수치 허용 범위 내에서 선의 연속적인 외곽 덮임을 요구한다. 도면에 빈 부분이 있는 창을 임의의 사각형으로 메우지 않았다.
- 창호도에 연결한 16개 창의 최대 외곽 폭 대조 차이는 약 `2.204e-8m`다. 원본 프레임과 재구성 외곽의 최대 수치 잔차는 약 `2.635e-7m`다. **추출·좌표 계산의 수치 일치값이며 도면 자체나 현장 시공의 정확도를 뜻하지 않는다.**
- 최종 공개 좌표의 유리 깊이 면은 원본 대조 면에서 최대 `5.508e-7m` 차이다. 좌표 반올림을 고려한 1µm 검사 범위 내다.
- 개구부 검사에서 호스트 벽 입체가 개구부 안에 남은 최대 투영 면적은 약 `1.961e-7m²`로 기존 허용 범위를 통과했다.
- IFC의 2,198개 요소·4,688개 구성요소에 대해 형식, 실제 형상, 체적, 세계 좌표를 검사했다. EXPRESS 오류 0건, JSON/IFC 세계 좌표의 최대 계산 차이 약 `2.5e-7m`다.
- BF 공간 자료·NavMesh를 다시 생성했다. 창호 장애물 272개의 경계가 수정 모델의 창호 외곽과 일치한다.
- 실제 공간 31개, 문 포털 98개, 승강기 연결 10개는 미확정 상태를 유지한다. 실제 건물의 성공 경로나 BF 인증 적합을 새로 확보한 것으로 보고하지 않는다.
- 원본 DWG와 보호한 추출·입력 파일의 해시 변경은 0건이다.

상세 수치는 `authoring-quality.json`, `window-geometry-validation.json`, `validation.json`, `preservation.json`에 기록했다. 오래된 형상 비교 보고서의 4,400개 구성요소 기준과 이번 비교 기준 4,503개를 혼동하지 않는다.

## 남은 문제와 다음 우선순위

창 272개 중 창호도 규격을 적용하지 못한 256개를 따로 기록했다. 249개는 유일한 평면 기호 연결을 확보하지 못했고, 5개는 원본 외곽이 불완전하거나 꺾인 창이며, 2개는 평면 외곽 폭과 창호도 폭이 일치하지 않는다. 기호 없음이 도면에 정보가 없다는 뜻은 아니며, 현재 자동 연결의 한계다.

구조 보 배치, 슬래브 실제 두께·FFL/SSL, 벽 구성층·상단, 출입문과 고정창 전체 조립체, 계단 방향과 코어 상세, 지붕·파라펫은 이번 단계에서 완료하지 않았다. 유리·프레임의 제조사 단면과 개폐 철물도 미확정이다.

다음 최우선 작업은 **1층 출입문의 한쪽 문짝 기호를 전체 문·고정창 조립체와 연결하는 것**이다. SSD-3/3a 같은 개정 변형, 문짝 폭과 전체 조립체 폭, 창호도의 적용 실을 함께 확인해야 한다. 이후 구조 평면의 보 기호를 층·경간 및 규격표와 연결하고 코어의 구조·마감 높이를 맞춘다.

생성기 수정은 로컬 `window_authoring.py`, `coordination.py`, `coordination_quality.py`, `architectural_assemblies.py`, `ifc_export.py`에 있다. 웹 배포에는 현재 JSON/IFC·뷰어 수정·웹 테스트와 문서를 포함한다. 기존 정밀 생성기와 다른 미커밋 작업, 원본·추출 자료는 기존 프로젝트 방식에 따라 로컬에 보존하며 원본 DWG는 게시하지 않는다.
