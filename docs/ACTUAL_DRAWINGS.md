# 실제 도면 분석 기록

작성일: 2026-10-10. 사용자가 승인한 **상세 형상이 남은 지상 1·2층**을 대상으로 합니다.

## 입력과 원본 보존

| 원본 | SHA-256 |
| --- | --- |
| `에너지-건축도면/A04-001~008 평면도.dwg` | `90c516d1db1bd6ca4d8c98f1ba16947f5f7ee9d40b039731b87fa640e96bf8eb` |
| `에너지-건축도면/A04-021~026 단면도.dwg` | `bdf8a493c6f46861776a1cf2060f3111afbd93f1d65799542b142e68e587dec6` |

기존 `cad_reader`와 작업 폴더의 ODA File Converter로 임시 복사본을 DXF R2018로 변환했습니다. 분석 전후와 재생성 전후 원본 해시가 일치했습니다. 원본 도면은 수정하지 않았습니다.

`$INSUNITS=4`이며 리더의 단위 판독 결과는 mm입니다. 모델 좌표는 m로 변환했습니다. 전체 평면도에는 여러 도면 묶음이 있으며, `xref-plan.dwg`와 `에너지 융복합단지-FORM.dwg`는 누락되어 해당 참조 내용이 추출되지 않았습니다. 상세 형상이 없는 묶음의 주석을 현재 모델의 실명과 혼합하지 않았습니다. 도면 개정 간 최신성 대조는 미완료입니다.

## 층 분리와 좌표 변환

| 항목 | 지상 1층 | 지상 2층 |
| --- | --- | --- |
| 원본 X 범위 (mm) | 32,920,000–33,020,000 | 33,046,150.00007091–33,146,150.00007091 |
| 원본 Y 범위 (mm) | −5,730,000–−5,640,000 | 동일 |
| 선택된 전개 객체 | 15,201개 | 8,881개 |
| 단면도 층 기준 | EL +37.70 | EL +41.90 |
| 모델 Z (m) | 0.00 | 4.20 |

1층의 변환은 `x=(원본x−32920000)/1000`, `y=(원본y+5730000)/1000`입니다. 2층은 먼저 X에서 시트 이동량 `126150.00007091 mm`를 추가로 제거합니다. 이 과정으로 두 층의 코어·기둥 위치를 같은 좌표계에 놓았습니다. 단면도 절대 EL은 모델 출처에 보존합니다. 다각형 연산에는 1 mm 정밀도 격자를 사용했습니다.

층 높이 근거는 단면도 `layout:Model/8F9D`의 `EL +37.70`, `EL+41.90` 텍스트입니다. 이 차이 4.20 m는 층 기준 간 거리이며 천장고, 벽 상단 높이, 슬래브 두께를 의미하지 않습니다.

## 생성 결과와 해석

| 모델 분류 | 개수 | 해석 |
| --- | ---: | --- |
| 벽체/경계 | 687 | 벽체 후보, 창호 경계, 외장 경계 및 짝 없는 면 표시 포함 |
| 기둥 | 84 | CAD 닫힌 단면에서 추출, 외부 기둥 포함 |
| 출입문 | 41 | 문 회전호를 이용한 개구부 후보: 1층 23, 2층 18 |
| 바닥 | 2 | 벽면 끝점의 오목 외곽으로 생성한 영역 후보 |
| 계단 | 2 | 계단 블록 외곽 후보 |
| 승강기 | 4 | E.V 표기와 CAD 블록 외곽 후보, 각 층 2개 |
| 합계 | 820 | 검토 전 요소; 확정 수량 산출 결과가 아님 |

실명 기반 장소는 15개입니다. 1층 홀·회의/세미나·식당·주방·기업지원 사무실·관리실·통신실·E.V, 2층 회의실·센터장실·센터사무실·홀·E.V를 포함합니다. 실명 텍스트의 위치를 장소로 저장했으나 실 경계와 문을 통한 연결 관계는 자동 확정하지 않았습니다.

평행한 벽면의 겹치는 길이와 간격을 이용해 벽체 후보를 구성했습니다. 짝이 없는 면의 폭 0.01 m는 표시용 폭이며 측정된 벽 두께가 아닙니다. 문 회전호 반지름은 문짝 후보 근거이며 유효 통과 폭은 `null`입니다. 바닥 후보는 중정·외부공간을 자동 제외하지 않았으므로 면적을 인증 또는 수량 산출에 사용하면 안 됩니다.

벽·기둥·계단은 단면도 층간 높이로 단순 압출했습니다. 문·승강기·바닥의 높이/두께는 미확인이므로 JSON에서는 `null`, IFC에서는 두께 없는 평면 형상으로 출력합니다. 웹의 얇은 표시는 선택을 돕는 시각화이며 실측 두께가 아닙니다. 문 개구부는 벽체 전 높이에 적용하는 초기 형상으로 인방과 문틀 상세는 없습니다.

## 검토 상태와 다음 작업

모든 요소는 `verified=false`로 시작합니다. 문 유효폭, 단차, 경사, 승강기 가동 상태는 미확인입니다. 층간 연결 `links`도 비어 있습니다. 현재 실제 모델에 경로가 없다는 결과는 건물이 접근 불가능하다는 판정이 아니라 **현재 자료로 통행을 검증하지 못했다는 의미**입니다.

검토는 다음 순서가 적절합니다.

1. 누락된 XREF와 개정 도면을 확보해 해당 묶음의 적용성을 확인합니다.
2. 층별 실내 바닥 경계를 확정하고 중정·외부공간·개구부를 제외합니다.
3. 벽체/창호/외장 면을 구분하고 출입문 개구부와 실 연결을 대조합니다.
4. 문 유효폭·단차·통로 폭·승강기 가동·계단/경사로 연결을 도면 또는 현장 자료로 확인합니다.
5. 확인한 속성과 형상을 웹에서 저장한 다음 실제 모델의 경로를 재검토합니다.

원본 기준 자료는 `cad_output/project-inventory.json`, `section-texts.json`, `energy-center-report.json`입니다. 대조 이미지는 `detailed-first.png`, `detailed-second.png`, 모델 미리보기는 `energy-center-preview.png`입니다. `python -m bf_bim.prepare_project`로 재생성하며 캐시는 원본 해시가 일치할 때만 재사용합니다.
