# 통합 3D Coordination Draft

기존 `precision-rebuild`의 CAD 경계 관측 결과를 보존하고 별도 `coordination-v2`에 건축 조립체를 생성한다. 이 결과는 도면 검토와 공간 확인용이며 설계 검증 완료 BIM이 아니다.

## 실행과 보기

```powershell
.venv-cad\Scripts\python.exe -m bf_bim.precise.rebuild --coordination --sync-web
.venv-cad\Scripts\python.exe tools/coordination_plan_qa.py
cd web
npm run dev -- --host 127.0.0.1 --port 5180
```

이미 실행 중인 개발 서버가 있으면 서버를 추가로 시작할 필요가 없다. 로컬 뷰어 `http://127.0.0.1:5180/?model=rebuild`에서 새 모델을 확인한다. 원격 push와 GitHub Pages 배포는 수행하지 않는다.

`표시 설정 → 검증 상태 표시`에서 전체 3D, 도면 기반 형상만, 검증 완료 부재만, 미확정 형상 강조를 선택한다. 기본 3D는 CAD 참조선과 입체 배치가 미확정인 상부 관측 면을 숨긴다. 도면 모드에서는 원본 선과 평면 관측 경계를 확인할 수 있다. 검증 완료 부재가 없으므로 검증 모드는 빈 상태를 명시한다.

`실내 시점`은 후보 실 경계 내부의 격자 점에서 벽·기둥·샤프트를 피하는 지점을 골라 진입한다. 공간 안에서 시야가 긴 방향을 선택하며 자유 시점 이동을 제공한다. 카메라 진입점은 BF 통행 경로나 법정 유효폭 판정이 아니다.

`IFC`는 Verified IFC, `Draft IFC`는 Coordination Draft IFC를 저장한다. Verified IFC는 검증 완료 입체가 0개이므로 층별 공간 계층만 포함한다.

## 구현 방식

* 원본 SHA-256과 네이티브 CAD 객체 ID를 대조하고 기존 폐합 공간·블록 후보를 사용한다. 이전 모델의 확대 슬래브, 틈 메움 조립체, 4층 외곽을 복사한 지붕은 사용하지 않는다.
* 기둥 211개 평면 관측을 유지한다. 동심 중복 단면의 큰 후보 하나를 검토용 입체로 표시하고 다른 후보는 미확정 관측으로 남긴다. 단면 크기만으로 일람표 부호를 확정하지 않는다.
* CAD 폐합 벽 경계를 먼저 사용하고, 대응 벽면 쌍은 미확정 경계 후보로 보완한다. 기둥·이전 벽체와 겹치는 조립 영역을 정리한다. 문과 창의 개구부 높이 구간을 분리하여 벽체 구성요소에서 절삭한다.
* 창호는 평면 축·측정 멀리언 위치를 이용한 창틀·유리 조립체로 생성한다. 문은 CAD 회전호의 위치와 잎 길이를 이용하고 닫힘 방향, 문 종류와 높이는 미확정으로 관리한다.
* 슬래브는 기존 폐합 건축 공간 후보를 사용하고 중정·계단·승강기 영역을 다시 제외한다. 건축 공간 경계와 구조 슬래브 경계는 동일하게 확정하지 않는다. 기존 150 mm 폐합 허용치와 가정을 기록한다.
* 기준층 계단은 CAD 단선과 A07 단면의 175×12 후보를 활용한다. 지하층은 실제 단선 반복을 골라 층간 3.9 m에 맞춘 검토용 높이를 사용한다. 지하층에서는 참·지지부·난간을 포함한 Z 형상에 3.9/4.2 배율을 적용하며 실제 적용 높이와 배율을 기록한다. 지하층 단높이, 진행 방향과 세부 참 배치는 미확정이다. 옥상 단선은 아래층으로 내려가는 계단일 수 있어 옥탑지붕까지 5.4 m를 올라가는 계단으로 늘이지 않고 평면 관측으로 남긴다. 난간과 경사 지지부도 미확정이다.
* 승강기는 E.V 블록의 샤프트 후보와 빈 내부를 생성한다. 실제 문과 겹치는 위치는 샤프트 조립체에서 절삭하지만 출입구 부호 대응은 검증하지 못했다. 임의 카·장비를 만들지 않는다.
* 옥상 경계는 자체 도면의 선망을 폐합한다. 옥탑지붕의 대형 하부 참조 경계를 제외하고 소형 폐합 경계만 관측으로 남긴다. 해당 경계의 기능과 아래 코어와의 대응이 불명확하므로 상부 입체로 확정하지 않는다.

## 가정과 상태

부재별 `validation_status`와 `property_status`는 위치·단면·높이·재료 등을 따로 기록한다. 허용 상태는 `verified`, `drawing_based`, `schedule_matched`, `provisional`, `unresolved`다. 이번 결과에는 `verified` 부재가 없으며 일람표의 위치 대응이 확정되지 않아 `schedule_matched`로 승격한 부재도 없다.

대표 가정은 슬래브 0.20 m, 마감 0.03 m, 문 높이 2.10 m, 창 높이 2.40 m, 창대 0.90 m, 프레임 폭 0.05 m, 표시용 유리 0.01 m다. 이 수치는 설계 사양이나 에너지 분석용 유리 물성값이 아니다. 부재의 `assumptions`, 구성요소 높이·Z, `applied_dimensions`, 원본 SHA와 CAD ID를 JSON·IFC에 기록하고 속성 패널에서 확인할 수 있다.

미세 Boolean 잔여 조각의 처리 기준도 공개한다. 1 μm 좌표 격자, 최대 10 μm 선형 단순화, 최소 조각 폭 0.1 mm를 사용한다. 벽체 절삭 결과에 0.1 mm 미만 목 부분이 남으면 반경 0.1 mm의 수치적 열기 연산으로 좁은 돌기·목을 제거한다. 제거 경계·면적·이유는 속성에 보존한다. 작은 면적이면서 목 부분이 0.1 mm 미만인 잔여 조각도 입체에서 제외한다. 입체가 남지 않은 후보는 미확정 의미 객체로 IFC에 보존하되 실패하는 표면 표현을 붙이지 않는다. 원본 관측 결과는 변경하지 않는다.

## 검증 자료와 한계

최종 수치와 통과 여부는 다음 실제 생성 자료에서 확인한다.

* `cad_output/precision-rebuild/coordination-v2/summary.json`: 부재·구성요소·층·상태 집계.
* `validation.json`: IFC4 EXPRESS, 각 표현의 좌표·면적·체적, 개구부와 수직 코어 후보.
* `plan-validation.json`, `plan-comparison-*.png`: CAD 선망과 생성 경계 비교. 기둥의 원본 경계 거리도 개별 저장한다.
* `browser/results.json`, 브라우저 캡처: 조감·입면·층별·실내·계단·옥상·수직 단면, 표시 모드와 BF 회귀.
* `preservation.json`: 원본 도면, 기존 모델, 앞선 엄격 재구축 결과의 해시 보존 검사.

조감도와 우측면 CG는 층 구성, 필로티, 코어와 상부 외형의 정성 비교에 사용했다. 이미지 픽셀에서 설계 치수를 산출하지 않았다. 창호 높이·상하 프레임 분할, 외장 마감, PV 설비, 난간, 파라펫과 옥탑 외벽은 CG와 동일하게 재현된 상태가 아니다.

기둥 경계의 약 0.00069 mm 차이는 앞 단계의 네이티브 관측 다각형과 새 JSON 경계를 대조한 직렬화 차이다. 원본 곡선 자체에는 앞 단계의 최대 0.5 mm 표본화 허용치가 별도로 적용된다. 이 수치를 건물 설계 정확도나 시공 오차로 해석하면 안 된다.

최종 생성 결과는 객체 2,198개와 구성요소 4,400개다. 기둥 관측 211개 중 동심 중복 후보 10개는 입체 중복 표시를 억제한다. 창호 272개, 문 98개, 계단 관측 10개(입체 9개·옥상 평면 1개), 승강기 샤프트 후보 12개가 포함된다. 상태 집계는 `provisional` 2,141개와 `unresolved` 57개이며 속성별 네이티브 위치·단면 상태를 별도로 보존한다.

Python 59개·웹 37개 테스트와 빌드가 통과했다. Draft IFC는 2,198개 제품·4,400개 조립 부품, Verified IFC는 제품 0개이며 두 파일의 IFC4 EXPRESS 오류는 0개다. 모든 IFC 형상의 좌표·면적·체적을 생성 JSON과 대조했다. 보호 대상 305개 파일의 변경은 0개다. 이 검사는 출력 일관성 검증이며 원본 설계 대조의 미확정 항목을 해소하지 않는다.

실제 Chrome WebGL 브라우저 검사에서 19개 장면 기록과 검증 모드 빈 상태 캡처를 생성했다. 조감·정면·측면·각 층·옥상·도면 모드·미확정 강조·층 분리·수직 단면·1층 실내·기준층 실내·계단·기존 모델 비교를 확인했다. JavaScript 오류는 0개였고 다운로드한 두 IFC의 해시는 생성 파일과 같았다. BF 교육용 모델의 1→2층 승강기 경로는 기존 32.6 m·71초 결과를 유지했다. 이는 실제 건물 BF 인증 결과가 아니다.

구조 보는 위치·부호·단면의 대응 자료가 없어 생성하지 않았다. PIT 본체·옥탑 외벽·파라펫 세부와 지하층 미폐합 바닥은 부분 복원에 머문다. 슬래브 구조 두께와 경계, 문·창호 일람표 대응, 개별 벽체 상단, 재료, 계단 방향, 승강기 장비와 PIT/상부 여유는 미확정이다. 코어의 층간 좌표 일치와 상단 레벨 확인은 실제 통행·설계 적합성 검증을 뜻하지 않는다.

BF 경로 알고리즘과 링크를 임의 보완하지 않는다. 새 모델의 공간·출입구는 검토 후보이며 BF 인증 모델로 취급하지 않는다. 기존 교육용 모델의 경로 회귀 결과와 실제 건물의 검증 상태를 분리한다.
