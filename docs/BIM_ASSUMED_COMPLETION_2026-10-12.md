# BIM 추정 보완과 접합 개선

사용자의 “확인되지 않는 부분은 임의로 정합하게 메워주라” 지시에 따라, 도면에서 직접 확인하지 못한 형상도 주변 부재와 층 높이에 맞춰 보완했다. 추가 형상과 수정된 후보에는 `user_assumed_completion`을 기록한다. 도면에서 확인한 원래 문, 창, 기둥의 평면 위치는 유지한다. 추정 부재는 검토 IFC에 포함하며 설계 검증 상태와 BF 사용자 검토 상태를 자동 승인하지 않는다.

## 실제 모델 변경

- 지하 1층과 지상 1~4층, 옥상의 바닥을 기존 벽과 기둥의 지지면까지 보완했다. 폐합 반경은 120mm, 기존 바닥에서의 최대 확장 범위는 300mm다. 기존 미확정 구멍은 유지하며, 이미 부재가 90% 이상 차지하는 지지면 구멍만 채운다. 계단, 승강기, 중정은 보존한다.
- S 표기와 단면표로 슬래브 두께를 배정하고, 원본 패널 경계가 없는 부분은 가장 가까운 표기의 영역으로 추정 분할했다. 1층 S1/S2/S3는 150mm, S4는 200mm다. 2~4층과 옥상은 150mm다. 1S4 표기는 현재 건축 바닥 경계에서 1.734m 밖에 있으므로, 인접 영역 배정의 근거로 사용하며 실제 패널 경계 확정으로 취급하지 않는다.
- 기존 G 보 155개를 유지하고, 추가 보 62개를 지지점에 연결했다. 미확정 G 배치는 가능한 기둥 지지점 중 가까운 후보를 선택하고, B 보는 같은 도면의 G 표기 오프셋과 양쪽 보 교점을 사용한다. 단면표가 있으면 해당 치수를 사용하고 없으면 400×700mm를 가정한다. 중정과 코어를 가로지르는 후보는 제외한다.
- 기존 부재로 설명되지 않는 CAD 벽선에 150mm 벽체 보완 86개를 추가했다. 문과 창 주변은 비워두고, 기존 벽과 기둥을 중복 생성하지 않는다.
- 문과 창의 기존 개구부 레벨 밖에만 불투명 상부 및 하부 벽을 보완했다. 기존 창호 프레임, 유리, 문짝, A10 규격 배정과 문 개구부는 유지한다.
- 겹치는 승강기 블록 외곽 후보를 두 구획으로 나눴다. 합쳐진 바닥 개구부 범위는 유지하고, 200mm 공유 벽과 150mm 외곽 라이닝을 가정했다. 원래 블록 외곽은 속성에 보존한다. 이는 실제 샤프트 내벽 치수의 도면 확정이 아니다.
- 옥상 코어와 정렬된 추정 옥탑 지붕, 150mm 두께와 900mm 높이의 추정 파라펫, 지하층 샤프트와 정렬된 PIT 2개를 추가했다. PIT는 기존 기준 높이 -5.5m를 사용하고, 지하층까지 1.6m, 바닥판은 200mm다. 옥탑 지붕은 현재 모델의 22.2m 기준을 따른다. 기존 미배정 옥탑 평면 관측은 원본 자료로 유지한다.
- 벽, 기둥, 보, 샤프트가 슬래브에 중복되는 체적을 실제 XYZ 교차부에서 제거했다. 보 상단은 FL-30mm에서 다시 만들고 현재 위치의 슬래브를 빼므로 150/200mm 패널 아래에 틈이 생기지 않는다.

## 형상 출력에서 발견하고 수정한 문제

접합부가 잘린 기둥을 일반 프로파일로 출력했을 때 IFC에서 약 170mm 좌표 차이가 발생했다. 수정된 접합부는 최종 윤곽의 닫힌 삼각망으로 출력하도록 바꿨다. 웹과 IFC에 같은 윤곽을 사용한다.

구멍과 외곽이 한 점으로 닿는 단면은 수직 모서리가 비정상적으로 중첩된다. 구멍을 막지 않고 0.1mm 간격을 열며 `numeric_hole_clearance_m`에 기록한다. 삼각망 측면도 상부 삼각망의 실제 경계 모서리를 사용한다. 거의 같은 Z 높이의 차이에서 발생하는 0에 가까운 두께는 생성하지 않는다.

전체 내부가 얇은 1mm 미만의 작은 교차 잔여는 벽으로 출력하지 않는다. 일부 변만 짧은 30×15mm 실제 코너는 보존한다. IFC가 약 0.124mm 잔여 벽의 면을 합쳐 체적을 다르게 읽는 사례를 검사로 확인했다. 제외한 윤곽과 이유는 부재의 `omitted_boolean_slivers`에 남긴다.

## 검증 범위와 한계

전체 IFC의 부재별 입체, 체적과 세계 좌표를 검사하고, 기존 문·창·기둥의 평면과 문·창 입체를 이전 Git 모델과 대조한다. 문과 창 개구부의 잔여 벽, 벽과 기둥의 중복, 계단·승강기·중정의 슬래브 개구부를 검사한다. 실제 건물의 경로 계산은 수행하지 않는다.

원본 구조 외부 참조의 실제 보 및 패널 경계가 여전히 누락돼 있다. 추정 배치와 패널 분할선은 실제 구조 설계 확인으로 바꾸지 않았다. 옥탑의 건축·구조 높이 표기에는 600mm 차이가 남아 있고 현재 모델 기준을 따른다. 실과 복도의 용도 및 연결은 기존 미확정 상태를 유지한다. 승강기 카, 기계 장비, 배근, 방수 상세와 창호 제작 상세의 설계 검증은 완료하지 않았다.

추정 추가 과정에서도 보 표기 후보 67건은 제외했다. 양쪽 기존 보 지지점이 확보되지 않은 51건, 보호 개구부를 가로지르거나 현재 지지 범위를 벗어나는 16건이다. 층별로 1층 11건, 2층 14건, 3층 16건, 4층 11건, 옥상 15건이며 `completion-validation.json`에 위치와 이유를 보존했다. 추정 허용을 받았어도 떠 있는 보나 코어를 막는 보를 생성하지 않았다.

다음 우선 작업은 샤프트와 코어의 실제 내벽 경계, 구조 패널 경계 및 작은보 위치를 원본 도면과 재배정하고, 추정 부재별로 치수와 레벨을 교체하는 것이다. 공간과 출입문의 실제 연결 확인은 그 형상을 기준으로 수행해야 한다.

## 재현 방법

```powershell
.venv-cad/Scripts/python.exe -m bf_bim.precise.rebuild --coordination --sync-web
.venv-cad/Scripts/python.exe -m tools.completion_quality_report
.venv-cad/Scripts/python.exe -m pytest tests -q
npm.cmd --prefix web test
```

생성 모델과 부재별 추정 근거는 `cad_output/precision-rebuild/coordination-v2/preview.json`, 정량 검사와 수정 근거는 `completion-validation.json`, 전후 비교는 `completion-comparison.json`에 저장한다. 브라우저 검사는 `tools/coordination_quality_browser_qa.cjs --model-only`로 실행하고, 경로 탐색을 호출하지 않는다.

1S4로 추정 배정한 면적은 18.320040m²다. S4 패널의 실제 경계가 복원된 면적이라는 뜻은 아니다. CAD 좌표 등록 최대 법선 잔차는 0.00000000405m로 기존 축선 등록을 유지했다. 지붕 파라펫은 기존 경계의 분절에 따라 60개 객체이며 별도 파라펫 설계 60건을 의미하지 않는다.

Python 전체 테스트 108개, 웹 테스트 67개와 TypeScript/Vite 빌드, Pages 하위 경로의 모델·IFC·스크립트·워커 자산 검사를 통과했다. PIT는 정차층 연결 후보에서 제외하고 기존 승강기 층간 후보 10개는 미확정으로 유지했다. 공간 검토용 삼각망은 원래 공간의 여유폭 경계와 교차하여, 새 장애물 경계의 원호 분할 때문에 미세하게 경계를 벗어나는 경우를 제거했다. 별도의 실제 출발지와 목적지 경로 검증은 수행하지 않았다. 기존 회귀 테스트에서는 미확정 조건의 통행 승인 차단을 유지하는지 검사했다.

실내 시점에서는 선택한 층의 카메라 위치를 유지하면서 실제 건물의 다른 층 부재도 표시한다. 상층 슬래브와 보, 계단 개구부 너머의 벽과 지붕이 층 표시 필터 때문에 사라지던 문제를 수정했다. 외관과 일반 층 검토는 기존 층 필터를 유지하고, 객체 숨김과 단면 설정도 유지한다. 추정 부재는 속성에서 추정 상태를 표시하고, 추가 보의 부호·단면 후보·지지점 간 거리를 확인할 수 있다.

Chrome의 실제 WebGL에서 전체 외관, 정면, 지하층과 1~4층, 옥상·옥탑·PIT, 층 분리, 단면, 각 층의 실내 시점, 기존 문·창 상세와 추정 보 속성 등 25개 화면을 확인했다. 390px와 320px 모바일에서도 가로 넘침이 없으며 실행 오류와 HTTP 오류는 0건이다. 결과와 캡처는 `browser-current/completion-results.json`과 같은 폴더에 보존한다.

사용자의 추가 요청으로 하단 도구 바를 축소했다. 데스크톱 실측은 271.17×34px, 모바일 390px 화면에서는 299.17×42px, 320px 화면에서는 271.17×42px다. 아이콘은 16px에서 14px로 줄이고 텍스트를 아이콘 중심으로 정리했으며, 접근성 이름과 툴팁, 모든 버튼 기능은 유지한다. 전체 홈페이지 구조와 디자인은 유지한다.
