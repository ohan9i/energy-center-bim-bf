# 1·2층 천장 구조 보완

1층 사무실·관리실의 실내 경계 후보 중 위층 슬래브 외곽 밖에 있는 약 49.002㎡에 상부 덮개 2개를 추가했다. 두께 150mm, 상단은 2층 기준 높이에서 30mm 아래인 추정 형상이다. 원본 천장·지붕 도면으로 확정한 마감 설계가 아니다.

2층에서 위층 슬래브 외곽 밖에 남은 추가 폐합 대상은 없었다. 슬래브 내부 개구부는 용도를 확정하지 못한 작은 구멍까지 유지했다. 1층 천장에 해당하는 2층 슬래브의 11개 구멍과 2층 천장에 해당하는 3층 슬래브의 23개 구멍을 보존한다. 기존 벽·기둥·보·문·창·슬래브 형상은 수정하지 않는다. 추가 덮개와 기존 입체의 겹침은 추가 부재 쪽에서 제거한다.

층별 3D의 **표시 설정 → 천장 구조 표시**를 켜면 위층에 소속된 슬래브와 하부 보가 표시된다. 1층은 2층 구조, 2층은 3층 구조를 가져온다. 일반 층별 검토의 초기 상태는 기존처럼 상부를 열어 둔다. 실내 시점은 천장과 건물 주변 구조를 자동으로 표시한다. 평면·CAD·객체 단독 표시에서는 이 추가 표시를 적용하지 않는다.

추가 덮개는 객체 탐색에서 `상부 덮개 추정 보완`으로 검색할 수 있다. 검토 IFC에 포함하며, 검증 IFC에는 추가하지 않는다. 천장 마감, 조명, 설비 배치는 이번 보완에 포함하지 않았다.

검증: 웹 테스트 65개 통과, 원본 도면 재구축 산출물이 필요한 3개는 생략했다. 기본 5초 제한에서 경로 테스트 2개가 시간 초과되어 단일 작업자·30초 제한으로 재실행했다. 천장 형상 테스트 2개, TypeScript/Vite 빌드, Edge WebGL의 두 층 천장 및 실내 시점·390px 모바일 표시를 확인했다. 브라우저 실행 오류는 0건이다. IFC의 부재 3,000개·구성요소 6,928개를 검사했다. 원본 DWG는 이 체크아웃에 없어 전체 DWG 재추출은 수행하지 않았다.

재현 명령:

```powershell
.venv-cad/Scripts/python.exe -m tools.complete_reviewed_ceilings
.venv-cad/Scripts/python.exe -m pytest tests/test_ceiling_completion.py -q
npm.cmd --prefix web test -- --maxWorkers=1 --testTimeout=30000
npm.cmd --prefix web run build
node tools/ceiling_browser_qa.cjs
```

공개 JSON을 입력으로 재현할 수 있으며, 전체 DWG 재구축에도 같은 생성 함수를 연결했다. 별도 BF 공간 데이터는 변경된 모델에 맞춰 재생성하며 기존 검토를 자동 승인하지 않는다. 검증 결과와 화면 캡처는 `cad_output/ceiling-review/`에 저장한다. 브라우저 검사는 Playwright와 Edge가 필요하며, `UI_QA_MODULE` 및 `UI_QA_CHANNEL`로 환경을 지정할 수 있다.
