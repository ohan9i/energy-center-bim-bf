2026-10-11, modelling_version 8 / revision 3. 로컬 구현·재생성·Chrome 검증 완료. 이후 사용자 요청에 따라 개선 전 모델을 삭제하고 현재 모델만 게시하도록 전환했다. 배포 방법은 [운영 안내](DEPLOYMENT.md)를 참고한다.

## 기하 검사와 시각 확인의 구분

- 문·창호 86개에 대한 호스트 개구부 조각 146건을 검사했다. 위 73개는 개선 전 대비 실제 잔여가 감소한 문·창호 수다. 생성 개구부와 해당 벽의 Z 범위 교차 검사에서 잔여 면적은 기준 0.00001㎡ 미만이다.
- 슬래브의 중정·계단·승강기 후보 침범과 기둥·벽 솔리드 중복은 기준 0.0001㎡ 미만이다. 지붕 윤곽 등에는 수치 반올림에 따른 극소 잔여가 있으므로 전부 수학적으로 0이라고 표현하지 않는다.
- 기둥 평면 윤곽 211개 보존. CAD 추출 윤곽과 최대 경계 차이는 약 `6.90e-7 m`. 추출·반올림의 내부 비교이며 건물 전체의 설계 정확도나 현장 오차가 아니다.
- 계단 입체 후보 9개 상부 참은 해당 층간 시각화 레벨과 일치한다. 지하 단면 반올림 표기와 층간 높이 차이는 0.06mm. 실제 진행 방향·접근성 검증은 아니다.
- Draft IFC: IFC4 EXPRESS 문제 0건, 요소 2,198개·구성요소 4,469개의 솔리드 체적·좌표를 JSON과 대조. Three.js는 같은 구성요소를 사용하고 실제 WebGL 렌더링을 확인했다.
- 건물 외관·층별 내부·단면·분리·계단은 화면에서 시각 확인했다. 변환 전 원본 AutoCAD 출력의 독립 대조, 개별 부재 단면·입면 설계 배정은 완료되지 않았다.

## 검증 완료 0개를 유지한 이유

고정값을 제거했지만 전체 근거 조건을 충족하는 입체 부재가 없어 산정 결과도 0이다. Verified IFC는 층 공간 구조만 포함한다. 승인 기록을 임의 생성하지 않았다.

기본 필수 항목은 부호·위치·윤곽·하단·상단·재료·적용 층·개정이다. 종류별로 문/창호 호스트·상하단, 계단 방향·단수·참 연결, 슬래브 개구부·구조 역할 등의 조건을 추가했다. BF `Element.verified`와 설계 검증을 분리했다.

명시적 검토 입력은 `cad_output/precision-rebuild/member-reviews.json` 또는 `--reviews PATH`로 받으며 policy는 `member-evidence/1`이다. 검토자·시점·원본 참조/해시, 구성요소 형상/재료 해시, 평면·높이·부재표 배정·접합·추출 범위 검사, 가정/미확정 해소 기록이 필요하다. 원본·형상이 바뀌면 이전 확인을 재사용하지 않는다.

## 파일과 확인 방법

- 개선 모델: `web/public/models/precision-rebuild.json`
- IFC: `precision-rebuild-verified.ifc`, `precision-rebuild-coordination-draft.ifc` (같은 폴더)
- 개선 전 모델 JSON·IFC와 비교 버튼은 최신 사용자 지시에 따라 삭제했다. 44개 벽체 후보의 원본 연계 관측만 `wall-remnant-observations.json`에 보존한다.
- 결과 폴더: `cad_output/precision-rebuild/coordination-v2/`
- 부재 검증: `member-validation.json`; 도면/규격 연결: `drawing-links.json`
- 층별 관계·44개 판정: `validation.json`; 전후 수치: `improvement-validation.json`
- 평면: `plan-comparison-*.png`, `improvement-plan-f1.png`; 실제 화면: `browser-v8/*.png`, `browser-v8/results.json`

Pages 경로로 빌드한 로컬 확인: `http://127.0.0.1:5182/energy-center-bim-bf/`. 재실행: `npm.cmd --prefix web run preview -- --port 5182 --strictPort`. 층 선택, 표시 설정의 검증 상태, 단면·층 분리, 객체 선택 후 속성별 도면 근거를 확인한다.

최초 재생성 시 원본·분석 입력의 보존 검사를 통과했다. 이후 비교 기준본은 사용자 삭제 지시에 따라 제거했으며 원본 DWG와 재생성 입력은 유지한다. 이전 전후 수치·화면 검사는 당시 기록이고, 현재 검사는 `tools/workspace_browser_qa.cjs` 및 `tools/coordination_quality_browser_qa.cjs`로 실행한다.

## 현재 모델만 게시하는 후속 변경

사용자 최신 요청에 따라 개선 전 비교 모델 JSON·IFC 3개와 로컬 기준본 5개를 삭제했다. 비교 로딩 버튼을 제거하고 저장소에서 비교본 ID 및 파생 ID를 정리한다. 다른 사용자 모델은 유지한다. 생성기는 전체 이전 모델 대신 44개 벽체 잔여 관측만 사용하며 비교 자산을 다시 생성하지 않는다.

현재 모델 재생성, 원본·입력 300개 보존 검사, JSON/IFC 전체 입체·좌표 및 EXPRESS 검사를 통과했다. 웹 테스트 41개, 관련 Python 테스트 12개 및 Pages 경로 HTTP 검사 통과. 현재 전후 수치 검사는 삭제된 이전 형상을 다시 계산하지 않고 기존 측정값을 명시적으로 사용하며, 현재 형상 검사는 새로 실행한다.

현재 모델만 대상으로 Chrome 전체·층별·계단·단면·층 분리·실내·모바일 및 IFC 다운로드 검사를 통과했다. 사용자 저장 모델 복원과 BF 테스트 입력 경로도 유지됐다. JavaScript·HTTP 오류 0건. 검증 캡처는 `browser-current/`에 생성했다. 배포 대상과 무관한 기존 미커밋 작업은 그대로 보존한다.
