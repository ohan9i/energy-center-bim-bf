# 실행·검증 결과

> 아래 수량과 결과는 이전 1·2층 구현 기록입니다. 이번 BIM 정밀화의 최신 검증 결과는 [BIM_REFINEMENT.md](BIM_REFINEMENT.md)에 정리했습니다. BF 테스트와 예제의 과거 기록은 보존합니다.

검증일: 2026-10-10. Windows, Python 3.12, Node.js 24 환경에서 실제 실행했습니다.

## 요청한 10가지 상황

| 요구 상황 | 확인한 내용 | 상태 |
| --- | --- | --- |
| 1. 벽체 통과 방지 | 모든 동일 층 경로 간선을 장애물과 몸체 여유폭으로 검사. 벽을 가로지르는 선분 거부 | 통과 |
| 2. 출입문 통과 | 유효한 개구부가 있을 때 강의실로 연결, 문 제외 시 벽을 복구하고 경로 없음 | 통과 |
| 3. 휠체어 조건 | 일반 보행자는 계단, 휠체어 이용자는 계단 없이 승강기 선택 | 통과 |
| 4. 승강기 층간 이동 | 1층 정문→2층 강의실 연결, 대기시간을 시간 계산에 반영 | 통과 |
| 5. 좁은 문 제외 | 유효폭 0.75 m는 휠체어 예제 조건에서 제외 | 통과 |
| 6. 경로 없음 | 폐쇄된 벽·가동 중지 승강기·미확인 문/바닥에 임의 경로 생성 없음 | 통과 |
| 7. 객체 수정 반영 | 문 폭을 0.75→1.10 m로 수정한 뒤 그래프를 다시 계산하면 연결 복구 | 계산 테스트 통과; 화면 조작 미검증 |
| 8. 도면 처리 오류 | 잘못된 확장자·손상 DWG·세션 만료 오류. 실제 도면의 누락 XREF 기록 | 통과 |
| 9. 위치 일관성 | 예제 IFC 형상을 실제 테셀레이션해 JSON의 XY 경계·층 높이와 비교. 실제 도면도 유형별 표본 대조 | 통과 |
| 10. 하위 경로 배포 | `/bf-test/` 방문자 빌드의 HTML·모델·규칙·자산·Worker URL을 HTTP로 확인 | 파일 로딩 통과; 브라우저 렌더링 미검증 |

경사로 경사 조건, 동일 출발/도착의 0 거리, 부적절한 이동속도, 누락된 층간 참조, 자기교차 다각형 및 바닥 개구부 오류도 검사했습니다. 예제 성공은 실제 건물 통행 검증을 의미하지 않습니다.

## 실제 도면과 실행 검사

- `python -m bf_bim.prepare_project` 실행 성공. 1·2층 JSON·IFC·도면 대조 이미지·모델 미리보기 생성, 원본 해시 유지 확인.
- 실제 모델은 820개 요소와 15개 장소입니다. 사용자 정의 휠체어 조건에서 미확인 실제 바닥을 통과하는 경로가 생성되지 않았습니다.
- 실제 IFC4 파일에 대해 `ifcopenshell.validate.validate(..., express_rules=True)`를 실행했습니다. 오류 0건이며 `IfcProduct`는 공간 계층을 포함해 824개입니다. 각 층의 벽·기둥·문·계단·승강기·바닥 12개 표본을 테셀레이션해 JSON과 XY 경계 및 Z를 대조했습니다. 미확인 높이는 평면으로 유지됩니다. 형식 적합성은 건축 형상 정확도 또는 BF 인증 적합성을 의미하지 않습니다.
- `start.ps1` 실행 후 `127.0.0.1:5173`의 Vite 프록시를 통해 상태·실제 모델·2층 PNG·실제 모델 IFC POST를 확인했습니다.
- 실행 스크립트의 재실행과 `stop.ps1`의 종료를 검사했습니다. Windows 가상환경 Python의 자식 프로세스까지 종료했으며 8000/5173 포트의 프로젝트 리스너가 남지 않았습니다.
- 층별 CAD 대조 이미지와 모델 미리보기는 이미지로 시각 확인했습니다.

하위 경로 재검사:

```powershell
cd web
$env:VITE_VIEWER_ONLY='true'
$env:VITE_BASE_PATH='/bf-test/'
npm.cmd run build
cd ..
.\.venv-cad\Scripts\python.exe tools/check_pages.py
```

이 검사는 임시 HTTP 서버를 사용한 후 종료합니다. 일반 로컬 빌드로 돌아가려면 환경 변수를 제거하고 다시 빌드합니다.

```powershell
Remove-Item Env:VITE_VIEWER_ONLY -ErrorAction SilentlyContinue
Remove-Item Env:VITE_BASE_PATH -ErrorAction SilentlyContinue
cd web
npm.cmd run build
```

## 남은 검사와 한계

이번 환경의 컴퓨터 제어 도구에 연결된 브라우저가 없어 웹 화면의 클릭·회전·선택·파일 저장과 모바일 배치를 직접 검사하지 못했습니다. HTTP 로딩 검사와 알고리즘 테스트를 전체 브라우저 QA로 간주하지 않습니다. 사용자의 후속 공개 요청에 따라 GitHub 원격 저장소와 Pages 배포를 추가했습니다. 배포 구성은 [배포 안내](DEPLOYMENT.md)를 참고하세요.

Vite 빌드에는 Three.js 청크가 약 518 kB로 500 kB 권고 크기를 넘는 경고와 Zod 라이브러리 주석 관련 경고가 있습니다. 빌드는 정상 완료합니다. Python 테스트에는 Starlette TestClient의 httpx 사용에 대한 폐기 예정 경고가 1건 있습니다.

실제 모델의 바닥 경계·중정·문 유효폭·실 연결·승강기 가동을 확인한 뒤 현장 자료와 경로를 대조해야 합니다. BF 기준의 개별 조항 및 법령 적용성 검토, 문 접근/회전 공간, 계단 단·난간, 경사로 3D 경사면과 인방 상세는 추가 작업입니다. [도면 분석 기록](ACTUAL_DRAWINGS.md)과 [README](../README.md)에 범위를 구분했습니다.
